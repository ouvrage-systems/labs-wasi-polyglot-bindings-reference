WASI v2: Webpack Bundler Integration

This sample demonstrates how to configure and build our WASM Component library using Webpack 5 with manual module resolution fallbacks.

Loading and compiling via Webpack...
How it works:
Webpack resolves the local dependency my-lib-v2. It handles the WebAssembly assets and mocks the Node-specific shims (like fs and os) using the fallback configuration in webpack.config.js.
