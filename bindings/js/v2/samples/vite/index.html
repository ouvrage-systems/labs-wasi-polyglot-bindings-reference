WASI v2: Vite Bundler Integration

This sample demonstrates how a developer imports our library as an NPM package in a modern React/Vite/Vue application compiled with bundlers.

Loading and compiling via Vite...
How it works:
Vite resolves the local dependency my-lib-v2, bundles the shims, and handles the static loading. No import maps are required because Vite handles module resolution on the host machine.
